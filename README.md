### 🛠️ Featured Projects

#### 🔀 [RouterNet — Multi-Domain LoRA Adapter Routing Engine](https://github.com/Niranjan-207)
A hot-swappable multi-adapter inference engine built on **Qwen3-4B**, combining a SentenceTransformer + Logistic Regression router for fast, accurate query classification.
- Achieved **96.8–98.4%** query classification accuracy for routing across domains
- Fine-tuned domain-isolated **LoRA adapters** (r = 16–32) to eliminate cross-task weight pollution
- Benchmarked hard vs. soft routing to guarantee **O(1) adapter switching under 0.02s latency**
- Boosted multi-step proof completion rates from **40% → 80%+** on a single T4 GPU (~8.2GB VRAM) via response-only loss masking and dynamic token budgeting, while maintaining **100% ground-truth math accuracy**
- **Tech:** Python · PyTorch · Hugging Face (Transformers, PEFT) · Sentence-Transformers · scikit-learn

#### ⚖️ [Nyaya-Verify — Contradiction-Aware RAG Pipeline for Legal Documents](https://github.com/Niranjan-207)
A verification-first RAG pipeline for Indian legal statutes that catches contradictions **before** generation.
- Built a **DeBERTa-v3 NLI cross-encoder auditing layer** to detect and filter repealed or conflicting provisions (e.g., old IPC vs. new BNS sections)
- Implemented dynamic K-scaling retrieval over **ChromaDB** with BGE-Small embeddings
- Optimized local inference on an RTX 4050 (6GB VRAM) via 4-bit quantization to co-run **Llama 3.1 (8B)** alongside the cross-encoder
- **Tech:** Python · LangChain · ChromaDB · DeBERTa-v3 · PyTorch · Ollama
